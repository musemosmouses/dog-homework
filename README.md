# The Dog Ate My Homework: Funniest Excuse

Entry for the make.fun bounty
`u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c`.

`main.ts` writes one line — a dog's excuse for eating the homework, in the
dog's own voice — to `/output/entry.txt` (1–200 characters, UTF-8).

> You said 'sit' and 'stay' — nobody ever said 'don't eat the homework.' I followed orders perfectly.

Run by the grader as `node main.ts` with `MAKEFUN_OUTPUT_DIR` set.
Deterministic: no network, no randomness, no clock.
